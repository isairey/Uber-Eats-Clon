# 🍔 Grub | Clon de UberEats

**Grub** es una aplicación fullstack tipo clon de UberEats, diseñada como plantilla completa para desarrollar apps de entrega de comida multiplataforma (Android, iOS, Web y Desktop).

Este proyecto permite construir aplicaciones modernas de delivery similares a UberEats, Foodpanda o GrubHub utilizando herramientas de desarrollo rápido.

---

## 📌 Descripción

**Grub** es una aplicación desarrollada como prueba de concepto basada en principios de desarrollo rápido (RAD), enfocada en la creación de interfaces reutilizables y altamente modulares.

El sistema incluye todas las funcionalidades esenciales de una app de entrega de comida, permitiendo escalar fácilmente hacia una solución completa conectada a backend.

---

## 🚀 Características

- 🌗 Modo claro / oscuro  
- 📱 Pantallas de introducción (Onboarding)  
- 🔐 Registro e inicio de sesión  
- 📍 Geolocalización  
- 🔍 Búsqueda avanzada  
- 🎛️ Filtros de búsqueda  
- 🍽️ Categorías de restaurantes  
- 🛒 Carrito de compras  
- 🎟️ Códigos promocionales  
- 💳 Gestión de pagos (tarjetas)  
- ❤️ Favoritos  
- 🚚 Seguimiento de pedidos  
- 👤 Perfil de usuario  
- 📱 Optimizado para Android e iOS  
- 🧩 Código altamente modular  
- ⚙️ Totalmente personalizable

## 💡 Funcionamiento

Esta aplicación es un prototipo visual (frontend), por lo que:

- No está conectada a un backend real
- La lógica es simulada para demostración
- Puede integrarse fácilmente con cualquier API o servidor
